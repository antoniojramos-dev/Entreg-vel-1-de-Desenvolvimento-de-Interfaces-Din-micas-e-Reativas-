# Meu Primeiro Projeto React

## Sobre o projeto

Projeto desenvolvido como atividade pratica de introducao ao React, utilizando Vite, JSX e componentes funcionais.

## Componentes desenvolvidos

- Header: apresenta o titulo da aplicacao.
- Footer: apresenta o texto do rodape.
- Card: recebe titulo e descricao atraves de props.
- Lista: recebe um array de strings e utiliza map() para renderizar uma lista dinamica.

## Reflexao: Abordagem Imperativa x Declarativa

A abordagem imperativa, utilizada no JavaScript puro, consiste em determinar passo a passo como o programa deve realizar uma acao. Para isso, o desenvolvedor manipula diretamente os elementos do DOM.

A abordagem declarativa, utilizada pelo React, consiste em descrever como a interface deve aparecer de acordo com os dados e estados da aplicacao. O React fica responsavel por atualizar a interface quando esses dados mudam.

O Virtual DOM otimiza a performance porque mantem uma representacao virtual da estrutura da pagina. Quando ocorre uma alteracao, o React compara a representacao anterior com a nova, identifica as diferencas e atualiza o DOM real apenas onde necessario, evitando manipulacoes desnecessarias.
